## Objectius

En acabar la sessió hauràs treballat aquests criteris:

- **RA4.a** · S'han configurat passarel·les, connectors o eines d'accés a cada un dels sistemes contenidors de dades per a automatitzar la captura d'informació i el seu procés.
- **RA4.b** · S'ha determinat la ubicació de les fonts de dades, confirmant-ne el format, la ubicació (local o núvol) i la distribució física i lògica.
- **RA4.c** · S'ha accedit a dades amb origen en bases de dades NoSQL usant els llenguatges d'accés o les API disponibles per a cada una.
- **RA5.b** · S'ha determinat la ubicació dels destins de les dades, confirmant-ne el format, la ubicació (local o núvol) i la distribució física i lògica.
