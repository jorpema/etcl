    Índices, mappings, Query DSL, agregaciones y API _bulk. Demo: NiFi vs Logstash vs Filebeat.

## Objetivos

Al terminar la sesión habrás trabajado estos criterios:

- **RA4.c** · Se ha accedido a datos con origen en bases de datos noSQL, usando lenguajes de acceso y/o API disponibles para cada una.
- **RA4.d** · Se han aplicado transformaciones y filtros a los datos con origen en bases de datos noSQL, tales como proyecciones, selecciones, agregaciones y ordenaciones, usando lenguajes de acceso propios de las mismas, en local y en la nube.
- **RA5.c** · Se han usado métodos de definición de datos para la creación de estructuras de almacenamiento en sistemas de bases de datos noSQL.
- **RA5.d** · Se han usado métodos para la carga, actualización y borrado de datos en bases de datos noSQL, ordinarios y masivos.
