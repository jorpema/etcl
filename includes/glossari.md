*[ETL]: Extract, Transform, Load: extraure dades de les fonts, transformar-les i carregar-les en un destí
*[ELT]: Extract, Load, Transform: primer es carrega i després es transforma dins del sistema destí
*[OLTP]: Online Transaction Processing: base de dades operacional, normalitzada, pensada per a moltes escriptures xicotetes
*[OLAP]: Online Analytical Processing: model pensat per a consultes d'anàlisi sobre molts registres
*[DDL]: Data Definition Language: CREATE, ALTER, DROP
*[DML]: Data Manipulation Language: INSERT, UPDATE, DELETE, MERGE
*[DCL]: Data Control Language: GRANT, REVOKE
*[DQL]: Data Query Language: SELECT
*[SCD]: Slowly Changing Dimension: com es gestionen els canvis dels atributs d'una dimensió
*[RLS]: Row Level Security: permisos fila a fila
*[CSV]: Comma-Separated Values: text pla amb una fila per línia i camps separats per un delimitador
*[JSON]: JavaScript Object Notation: format de text amb objectes clau-valor i llistes, que poden estar niats
*[XML]: eXtensible Markup Language: format de text amb etiquetes niades
*[API]: Application Programming Interface: punt d'accés perquè un programa demane dades a un altre
*[IoT]: Internet of Things: dispositius i sensors connectats que generen dades
*[SCADA]: Supervisory Control And Data Acquisition: sistema industrial que supervisa i recull dades de sensors i màquines
*[SMP]: Symmetric Multiprocessing: diversos processadors que comparteixen la mateixa memòria en un sol servidor
*[MPP]: Massively Parallel Processing: molts nodes independents, cadascun amb la seua CPU, memòria i disc, que treballen en paral·lel
*[HDFS]: Hadoop Distributed File System: sistema de fitxers distribuït en diversos nodes
*[JDBC]: Java Database Connectivity: estàndard de connexió a bases de dades que usa NiFi
*[RDF]: Resource Description Framework: model de dades en triples subjecte-predicat-objecte
*[OWL]: Web Ontology Language: llenguatge per a definir ontologies
*[SPARQL]: llenguatge de consulta per a dades RDF
*[MQTT]: protocol lleuger de missatgeria publicar/subscriure per a IoT
*[ODS]: Operational Data Store: còpia integrada i recent de les dades operacionals
*[KPI]: Key Performance Indicator: indicador clau
*[BI]: Business Intelligence: anàlisi de dades per a la presa de decisions
*[RGPD]: Reglament General de Protecció de Dades
