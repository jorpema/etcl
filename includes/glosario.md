*[ETL]: Extract, Transform, Load: extraer datos de las fuentes, transformarlos y cargarlos en un destino
*[ELT]: Extract, Load, Transform: primero se carga y después se transforma dentro del sistema destino
*[OLTP]: Online Transaction Processing: base de datos operacional, normalizada, pensada para muchas escrituras pequeñas
*[OLAP]: Online Analytical Processing: modelo pensado para consultas de análisis sobre muchos registros
*[DDL]: Data Definition Language: CREATE, ALTER, DROP
*[DML]: Data Manipulation Language: INSERT, UPDATE, DELETE, MERGE
*[DCL]: Data Control Language: GRANT, REVOKE
*[DQL]: Data Query Language: SELECT
*[SCD]: Slowly Changing Dimension: cómo se gestionan los cambios de los atributos de una dimensión
*[RLS]: Row Level Security: permisos fila a fila
*[CSV]: Comma-Separated Values: texto plano con una fila por línea y campos separados por un delimitador
*[JSON]: JavaScript Object Notation: formato de texto con objetos clave-valor y listas, que pueden estar anidados
*[XML]: eXtensible Markup Language: formato de texto con etiquetas anidadas
*[API]: Application Programming Interface: punto de acceso para que un programa pida datos a otro
*[IoT]: Internet of Things: dispositivos y sensores conectados que generan datos
*[SCADA]: Supervisory Control And Data Acquisition: sistema industrial que supervisa y recoge datos de sensores y máquinas
*[SMP]: Symmetric Multiprocessing: varios procesadores que comparten la misma memoria en un solo servidor
*[MPP]: Massively Parallel Processing: muchos nodos independientes, cada uno con su CPU, memoria y disco, que trabajan en paralelo
*[HDFS]: Hadoop Distributed File System: sistema de ficheros distribuido en varios nodos
*[JDBC]: Java Database Connectivity: estándar de conexión a bases de datos que usa NiFi
*[RDF]: Resource Description Framework: modelo de datos en tripletas sujeto-predicado-objeto
*[OWL]: Web Ontology Language: lenguaje para definir ontologías
*[SPARQL]: lenguaje de consulta para datos RDF
*[MQTT]: protocolo ligero de mensajería publicar/suscribir para IoT
*[ODS]: Operational Data Store: copia integrada y reciente de los datos operacionales
*[KPI]: Key Performance Indicator: indicador clave
*[BI]: Business Intelligence: análisis de datos para la toma de decisiones
*[RGPD]: Reglamento General de Protección de Datos
*[ACID]: Atomicidad, Consistencia, aIslamiento y Durabilidad: garantías de las transacciones
*[CAP]: Consistency, Availability, Partition tolerance: en un sistema distribuido solo se pueden garantizar dos a la vez
*[NLP]: Natural Language Processing: procesamiento del lenguaje natural
*[SIG]: Sistema de Información Geográfica
